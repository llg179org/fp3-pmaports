# A-B-A on the r76 sleeping baseline, short.
#
# ☠️ The first version of this file was two full slope-leg runs, each with its
# own descent AND a wait to 97 % - about fourteen hours for what is really a
# comparison between legs.
#
# Two things make it short, and the second one is the bigger:
#
#  1. SLOPE_SLEEP/SLOPE_CYCLES/SLOPE_SETTLE were hardcoded 900/6/1800 inside
#     slope-leg.sh and are now parameters (defaults unchanged, so every earlier
#     leg still reproduces). Here: 4 x 600 s with a 600 s settle, ~55 min a
#     phase instead of 2 h 40.
#
#  2. ☠️ The recharge between legs stops at 90 %, not 97 %. The taper above
#     ~95 % is the slowest part of a charge and it buys NOTHING here: the leg
#     descends to a FIXED 4.03 V target before it measures anything, and
#     slope-leg.sh says so itself ("the leg DESCENDS to a fixed TARGET anyway,
#     so where it starts above START_MIN does not matter"). START_MIN is 4.2 V
#     and 90 % clears it comfortably. START_CAP is lowered to match; leaving it
#     at 95 would abort legs 2 and 3 on a pack that is perfectly good for them.
#
# ☠️ Compare phase-A SLOPES between the three legs; the derived mA is for scale
# only. A' is not optional: 2026-08-25 produced TWO results that were pure
# drift and would have been published as effects without a control.
#
# The configuration under test is the one the goal asks for and that was proven
# reachable at 18:06 the same day: asleep, radio up, the modem's SMD edge armed
# as a wakeup source, an incoming call raising the phone in one second.
@preflight 95
@charge 97 90

@note A - r76 sleeping baseline, radio up, nothing cut
@timeout 9000
SLOPE_SLEEP=600 SLOPE_CYCLES=4 SLOPE_SETTLE=600 /root/slope-leg.sh A-baseline-r76-20260825

@charge 90 75
@note B - the same with the modem stack cut: the one comparison available without a build
@timeout 9000
START_CAP=85 SLOPE_SLEEP=600 SLOPE_CYCLES=4 SLOPE_SETTLE=600 /root/slope-leg.sh B-nomodem-r76-20260825 ModemManager rmtfs tqftpserv

@charge 90 75
@note A-prime - control, identical to A, so a drift across the night cannot be read as an effect
@timeout 9000
START_CAP=85 SLOPE_SLEEP=600 SLOPE_CYCLES=4 SLOPE_SETTLE=600 /root/slope-leg.sh Aprime-baseline-r76-20260825
