# Measured 2026-08-19 19:35: one restart and the DSP power-collapses in every
# suspend afterwards, crystal off for the whole of it. This leg is what that is
# worth in mA, against baseline-20260819 (phase-A slope -35.77 mV/h).
#
# ☠️ Compare phase-A slopes directly. The derived mA is for scale only.
@preflight 95
# ☠️ slope-leg.sh needs a pack above START_CAP, which was 99 % until 2026-08-19
# and is 95 % now. The old gate could not be satisfied in the state it usually
# found: with the charger attached and the pack terminated, the system runs off
# USB, battery current reads 0, and the pack never falls to the 4.30 V recharge
# threshold - so "wait for 99 %" waited forever. The leg descends to a fixed
# 4.03 V target anyway, so where it starts above START_MIN does not matter.
@charge 95 60
@note restart the ADSP, gate on a probe suspend, then a full slope leg
@timeout 21600
/root/adsp-restart-leg.sh adsprestart-20260819
